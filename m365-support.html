This is the support page for LinkSheet for Microsoft 365, an Excel add-in by CropSettle LLC that hyperlinks the files in a OneDrive folder into your workbook. Below are quick-start steps, answers to common questions, and how to reach us directly. This page is about the Excel add-in only; our other products have their own support pages.

The folders you see in the add-in are in OneDrive, not on your computer. An Excel add-in runs inside Excel's browser sandbox and cannot see your hard drive. If your documents live on your PC or in Google Drive rather than in OneDrive or SharePoint, this add-in cannot reach them — move them into OneDrive first, or use the LinkSheet product built for where they are.

Getting started

  1. Open a workbook in Excel. On the Home tab, choose LinkSheet → Link Files. The panel opens on the right.
    Not there? In Excel's Single Line Ribbon layout the button sits in the overflow menu (the » or chevron at the right end of the ribbon). Switching to Classic Ribbon shows it in full.
  2. Press Sign in to OneDrive. On Excel for the web this is usually silent, because Excel vouches for the account you are already using. Elsewhere Microsoft may open a sign-in window and show the two permissions the add-in asks for (your name, and read-only access to your files).
  3. Browse to the folder that holds your documents and press Use this folder — the button under the folder path, not the folder's row.
  4. Select the worksheet whose cells name your files, then press Link Files. Every cell whose text matches a file name in the folder becomes a hyperlink to that file. The report lists each cell that was linked and each one that was not, and why.

Frequently asked questions

Nothing was linked.

Link Files matches a cell's text to a file name (without its extension) in the folder you chose. Check that the sheet that was active when you pressed the button is the one with the names in it, and that the folder holds the files themselves rather than a further subfolder. By default only the chosen folder is read, not the folders inside it. Numbers that look like quantities, money, dates or percentages are deliberately not linked, so 28743.79 will not be linked to 28743.pdf.

Some cells say "ambiguous".

Two or more files could be the right one and the add-in will not guess. Rename one of the files, or make the cell text more specific, and run again. Cells that were linked are not affected.

The report says a file name appears more than once.

When the same file name exists in two places in the scanned folders, the first one found is used and the report names the one that was not, so you can check it. If that is the wrong choice, rename one of the files.

What does Repair Broken Links do?

When a workbook is moved from a PC to OneDrive, its hyperlinks still point at the old PC folder or network share, so they open nothing. Repair reads every link in the workbook, and for each one that points at a PC path or network share it looks for a file of exactly that name in the folder you chose (including its subfolders). If exactly one file matches, the link is re-pointed at it; the cell's text is not changed. Anything Repair cannot resolve is listed, never guessed: a name that exists twice, a name with a different file type, a link to a folder, a link whose address is calculated by a formula, or a name not in the folder at all. Web links are left alone — the add-in only reads where a link points and never follows it, so it cannot tell whether a web address still opens.

Repair stopped and said it had used its allowance.

The plan without a key includes a limited number of Repair runs; a run that repairs nothing is not counted. If you have a key, paste it into the Key box in the panel. If you do not, write to us and we will explain the options for your situation.

Will it change or delete my data?

The add-in only ever writes hyperlinks onto cells. It never changes cell values, never writes over a formula, and never creates, changes, moves or deletes anything in OneDrive. Clear Hyperlinks removes the links from every sheet in the workbook and resets the font colour of the cells that carried one; the text stays. The add-in does not make backup copies — Excel's own Version History (File → Info) is the undo for any run.

What does the add-in access?

The open workbook's cells, and the names and links of the files in the folder you choose. It never opens or downloads a file's contents, and nothing is sent to CropSettle LLC — we run no server. The full policy is at cropsettle.com/m365-privacy.html.

I have a key. Where do I enter it?

In the panel, paste the whole key (it starts with LSM1.) into the Key box and press the button beside it. The panel confirms that the key was accepted and, if your browser will not keep site data, tells you that the key will need to be entered again next time. Remove key deletes it from that browser. A key issued for LinkSheet for Google Sheets is a different product and will not be accepted here.

How do I remove the add-in?

In Excel, Insert → Add-ins → My Add-ins, open the menu on the LinkSheet tile and choose Remove. Links already written into your workbooks stay as they are — they are ordinary Excel hyperlinks.
